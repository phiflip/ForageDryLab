# Forage Drying

Interactive Streamlit app for the lecture **Forage Conservation**.

The app is designed to help students understand the physical relationships involved in forage drying, especially:

- saturation humidity and absolute humidity
- saturation deficit (SD)
- dew point and dew formation at the forage surface
- saturation deficit sum (SDS)
- simplified drying dynamics over time

The app is intended as a **didactic model** and not as a weather or drying forecast tool.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
